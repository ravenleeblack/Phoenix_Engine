Build

make all
make engine
make editor
make game
make loader

Clean

make clean_engine
make clean_editor
make clean_game
make clean
make clean_prefs
make clean_all

make clean preserves 01_bin/phoenix_editor.pdb. Use make clean_prefs or make clean_all to reset saved editor settings.

Run

Press F5 in VS Code or run 01_bin/phoenix_engine.exe. Keep the executable next to its DLLs and preferences file.
